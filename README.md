## Dataset description
_ Source: https://www.kaggle.com/datasets/vinayakshanawad/heart-rate-prediction-to-monitor-stress-level  

_ Description: It contains multiple input features designed to predict an individual’s heart rate using a regression model. The goal is to leverage heart rate predictions as a potential proxy to monitor stress levels in real time (about 369k rows, public)
